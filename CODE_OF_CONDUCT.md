# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good intent, and keep discussion about the work. Report unacceptable
behavior privately to the maintainer through a
[GitHub security advisory](https://github.com/tchoedak/mcp-contrast/security/advisories/new)
or by contacting [@tchoedak](https://github.com/tchoedak).
